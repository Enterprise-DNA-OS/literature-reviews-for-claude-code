# Why no front end

Review records, sources, screening decisions and checks are ordinary data. Ask Claude Code, Codex, OpenCode or Cursor to run the command and show its output. Change the question or document with a migration and a new query.

npm run view and npm run docs generate static branded HTML. They have no editing controls, scheduled refresh or multi-user session. A screen normally provides document reading, annotation, keyboard screening, blinded reviewer work, mobile access and synchronous collaboration. This local desk provides none of those interfaces. Use the original reports and a separate blind-review process when required.

There is no automatic literature search, full-text fetch, article interpretation, statistical synthesis or publication service. Research decisions stay with people. Enterprise DNA can build the specific interface and integrations your version needs, with an agreed setup fee and retainer.
